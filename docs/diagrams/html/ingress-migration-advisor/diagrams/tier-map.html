Overview / ingress-tier-map.yaml
Step 0b · Required input — HALT if missing

docs/ingress-tier-map.yaml

The advisor requires an explicit tier map in the consumer repo so critical services are never auto-scheduled. It lives next to docs/PROJECT.md and is reviewed via PR like any policy change — the tier map is the one source of truth for the critical-tier veto.

File format

# docs/ingress-tier-map.yaml — sibling of docs/PROJECT.md
schemaVersion: 1
services:
  argocd-server:   critical
  harbor:          critical
  grafana:         standard
  kibana:          standard
  chartmuseum:     standard
  mlflow:          low
  registry-mirror: low
# Services not listed default to "standard" with a WARN.

Valid tier values

TierEffect on the advisor
criticalVetoed — forced to defer; never scored, never batched
standardTraffic-tier dimension scores 2 (also the default for unlisted services)
lowTraffic-tier dimension scores 1; low-tier services sort first in batches
anything else⛔ HALT at Step 0b — validation error, regardless of --strict-tier-map

Validation matrix at Step 0b

ConditionDefaultWith --strict-tier-map
File missing entirely⛔ HALT⛔ HALT
Map entry not present in inventory (orphan)⚠ WARN⛔ HALT
Inventory service missing from map⚠ defaults to standard + per-service WARN⚠ same
Invalid tier value⛔ HALT⛔ HALT
# HALT message when the file is missing
docs/ingress-tier-map.yaml not found. The advisor requires an explicit
tier map so critical services are never auto-scheduled. Create the file
with the format documented at the bottom of this SKILL.md, then re-run.

Why a file, not a flag

  • The critical-tier veto is policy, not a flag — there is no --force-critical bypass.
  • To migrate a critical service in a given cycle, the team PRs the tier map first; the change is reviewed like any other policy change.
  • The map is persisted into state.yaml.inputs.tierMap so every plan records exactly which policy it was generated under.
⚠ Plans age: each run snapshots the tier map at that point in time. --resume does not re-read the map — re-run from scratch after a tier change.
