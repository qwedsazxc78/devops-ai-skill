The five scoring dimensions

Each non-vetoed service scores 1 (low risk), 2 (medium), or 3 (high) per dimension, with equal weights — the total is a simple sum. Range is 4–14: five dimensions × max 3 would give 15, but traffic tier caps at 2 because tier-3 (critical) never reaches the rubric — it is vetoed first. The rubric lives in a plain markdown table parsed at runtime; reweighting is a PR, not a code change.

Dimension 1 · Annotation complexity

Total annotation count plus estimated unknowns. An annotation is "unknown" if its key matches no row of gateway-api-migration/references/annotation-map.md.

ScoreCriteria
1≤ 5 total annotations AND 0 unknown
26–15 total OR 1–2 unknown
3> 15 total OR > 2 unknown

Dimension 2 · TLS mode

How the Ingress terminates TLS today.

ScoreCriteria
1spec.tls[].secretName references a cert-manager Secret
2networking.gke.io/managed-certificates annotation (GKE ManagedCertificate)
3Mixed (some hosts secret, some managed-cert) OR no TLS at all

Dimension 3 · Hostname count per env

Takes the maximum across envs — a service with 4 hosts in prd but 1 in dev scores 3.

ScoreCriteria
11 host
22–3 hosts
3≥ 4 hosts

Dimension 4 · Traffic tier (caps at 2)

From docs/ingress-tier-map.yaml. The only dimension that cannot score 3 — score-3 is reserved for the veto path.

ScoreCriteria
1low
2standard (also the default for unlisted services, with a WARN)
—critical → veto rule: forced to defer, dimensions left empty

Dimension 5 · Auth / CORS / security annotations

Counts distinct security-relevant annotation categories present:

  • CORS — any cors-* or enable-cors
  • Auth — any auth-*, basic-auth, whitelist-source-range
  • Security headers — any *-snippet with security header manipulation (annotation-map row 9a)
  • WAF / cert-only — force-ssl-redirect, ssl-passthrough
ScoreCriteria
10 categories present
2exactly 1 category present
32+ categories present

Worked example — state.yaml.scores[]

scores:
  - service: argocd-server
    vetoed: true
    vetoReason: critical-tier
    dimensions: {}     # empty when vetoed — never scored
  - service: grafana
    vetoed: false
    dimensions:
      annotationComplexity: 1
      tlsMode: 1
      hostnameCount: 1
      trafficTier: 1
      securityAnnotations: 1
    total: 5          # 4–7 band → direct-gateway
⚠ The model never re-derives scores in natural language — score_services.py parses the rubric tables from references/scoring-model.md at runtime and emits structured YAML. A scoring-script crash is a HALT (treat as a bug, report and re-run).
