ingress-migration-advisor

Read-only EOL planner: inventories every Ingress across all Kustomize overlays, scores each service on five migration-readiness dimensions, and recommends one of four paths per service. It produces a plan with a Mermaid Gantt and ready-to-paste Zeus commands — it never mutates the repo and never invokes the migration skills itself.

devops:zeus · *ingress-migration-advisor · detailed Read-only — re-running is always safe
Seven-step pipeline — red borders are HALT gates · no file is ever written outside docs/reports/ and /tmp
Step 0 · Gate
Tool check
kustomize · yq · git · python3. HALT with install hints if missing. No cluster tools — fully offline.
Step 0b · Gate
Operator inputs
EOL deadline (ISO) + batch size cap (default 5). HALT if docs/ingress-tier-map.yaml is missing or deadline is in the past.
Step 1 · Gate
Inventory
kustomize build every common.*/overlays/* → classify rendered Ingresses. HALT if zero Ingresses or all builds fail.
Step 2
Score
Critical-tier veto first, then 5 dimensions for non-vetoed services. Total range 4–14.
Step 3
Decide path
Veto → sourceClass shortcut → score bands. direct-gateway · two-step · swap-only · defer.
Step 4
Batch
Group by path + score ±2, weekly cadence from next Monday, fit inside deadline − bake buffer. Commands deduplicated per overlay.
Step 5
Render plan.md
Mermaid Gantt + per-service decision table + per-batch Zeus command blocks + deferred/risk register.
Step 6
Summary
Totals per path, deadline margin, plan path printed to session. Never auto-commits.
Usage
*ingress-migration-advisor # interactive: prompts for deadline + batch size
*ingress-migration-advisor --deadline 2025-10-31 # explicit EOL deadline
*ingress-migration-advisor --target-path two-step # one global path for all non-vetoed services
*ingress-migration-advisor --strict-tier-map # HALT on orphan tier-map entries
*ingress-migration-advisor --resume <state-path> # re-render plan only — no re-scoring
