Verdict model + output artifacts

Every run ends with exactly one verdict written into state.yaml and printed to the operator, plus a report directory that doubles as the audit trail and the --resume checkpoint.

The four verdicts

VerdictCauseWhat the operator does
READYBoth scans clean, DNS bake confirmed, plan generatedRead plan.md, drive commands.sh block-by-block
BLOCKEDActive nginx Ingress found (Step 3, exit 1) or DNS bake declined (Step 4)Re-migrate the leftover or delete the stale Ingress; retry. commands.sh is NOT written
NEEDS_REVIEWOperator bypassed the DNS bake gate with --skip-dns-bakeThe override is recorded — a human must review before executing the plan
DEGRADEDA scan could not run (Step 3, exit 2 — e.g. kubectl missing, cluster scan skipped)Re-run with full tooling, or accept the partial-evidence risk explicitly

Report directory

docs/reports/traefik-controller-decommission/<date>/
  state.yaml     # machine-readable state (--resume checkpoint)
  verify.json    # raw cluster + repo scan results
  plan.md        # operator-readable plan
  commands.sh    # copy-paste-ready (NEVER auto-executed)

state.yaml essentials

discovery:
  nginxModule: common.ingress-nginx
  argocdAppManifests: [common.ingress-nginx/argocd/dev.yaml, ...]
  nginxNamespace: ingress-nginx
verification:
  activeNginxIngresses: { cluster: [], repo: [] }
  dnsBakeConfirmed: { confirmed: true, confirmedBy: ..., confirmedAt: ... }
plan:
  archive: { sourcePath: common.ingress-nginx, targetPath: archive/common.ingress-nginx }
  lbRelease: null  # null if --no-lb-cleanup
verdict: READY | BLOCKED | NEEDS_REVIEW | DEGRADED

Next-step instructions printed on completion

  • Read docs/reports/traefik-controller-decommission/<date>/plan.md
  • Execute commands.sh block-by-block (not in one shot)
  • Commit the report directory once decommission is complete
⛔ The skill stops here by design. It never runs helm uninstall or kubectl delete itself — ArgoCD's pruner removes the controller once the operator pushes the archive commit and disables the Application.
