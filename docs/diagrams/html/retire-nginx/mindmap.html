  • ✅ When to run

    all three must hold
    • Replacements liveevery service has an active HTTPRoute or Traefik Ingress
    • DNS cut overA-records point at the Traefik / Gateway LB
    • nginx idleno live traffic on the nginx controller

  • 📜 Core rules

    never broken
    • Overlay edits only$patch: delete in the env kustomization — base files stay for other envs
    • One file kills the controllerdelete argocd/<env>.yaml; prune + finalizer cascade do the rest
    • Right zerovalidate nginx-class = 0, not Ingress-total = 0
    • Ordered envsall = dev → stg → prd, validating each
    • archive/ is fair gamemigration snapshots, never referenced — safe to delete

  • ⚙️ Eight steps

    per environment
    • 1 Parseenv arg or interactive detection
    • 2 Pre-flightbuild baseline + inventory verdict
    • 3 Discoverynames via kustomize build, not grep
    • 4 Plan + confirmDELETE / PATCH / KEEP, wait for yes
    • 5 Executeapp yaml, patches, orphans, archive/
    • 6 Validatezero nginx-class + regression builds
    • 7 Module cleanupafter all: archive common.ingress/
    • 8 Reportsummary table + commit message

  • ⛔ Safety gates

    abort > outage
    • Broken buildhard abort — never retire a broken overlay
    • nginx > 0, replacements = 0hard abort — nginx is the only routing path
    • nothing at allhard abort — migration not done
    • already retiredsoft warn + confirm (cleanup-only rerun)
    • regression failurehalt — other env broke, do not commit

  • ⚠️ Edge cases

    learned in production
    • Class-override patchfile named *nginx* but renders gce/alb — keep it, rename only the file
    • Never rename metadata.namedelete + recreate reprovisions the cloud LB
    • namePrefix orderpatches run before prefixing — target un-prefixed names
    • No delete + same-name resourceKustomize duplicate-ID error at accumulation
