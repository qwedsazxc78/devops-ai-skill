Pre-flight safety gates

All checks run before touching any file. The overlay is built once to /tmp/retire-nginx-<env>.yaml and reused for every check.

2a · Build baseline

kustomize build common.service/overlays/<env> > /tmp/retire-nginx-<env>.yaml
# exit code must be 0 — never retire a broken overlay

2b · Inventory verdict matrix

The breakdown of nginx vs replacement resources decides whether retirement is safe:

2c · Active nginx entries — class-override cross-check

A file named *-nginx-* in the overlay's patches: may actually patch the nginx base resource to a different ingress class (e.g. GCE or ALB). The rendered manifest is the source of truth, not the file name:

  • Rendered ingress.class is gce / alb / traefik → class-override patch: keep it, never $patch: delete it
  • Rendered ingress.class is nginx → genuine dependency: warn, require explicit confirmation
⚠ Services with active nginx-class patches still depend on nginx for routing. Retiring the controller removes their routing path — migrate them first.
