nginx-to-gateway

Thin orchestrator that chains nginx-to-traefik (class swap) and gateway-api-migration (resource swap) against one Kustomize module in one operator session. Owns no conversion logic — it sequences the two sub-skills, reads A's outputs.traefikIngresses[] hand-off, and records the chain in docs/reports/nginx-to-gateway/<slug>/index.yaml.

Hand-off contract

State files + index.yaml

Steps C.2 / C.4 / C.5

Failure + resume

A halts → B blocked, chain FAIL. B halts → A's outputs intact, resume runs B only. C halts after B → resume re-runs the index render only.

Design guarantees — what this skill never does

  • Owns no conversion logic (A and B do all the work)
  • No DNS scripts
  • No cluster apply
  • No auto-commit
  • No state merging between phases
  • No re-validation of A's outputs
