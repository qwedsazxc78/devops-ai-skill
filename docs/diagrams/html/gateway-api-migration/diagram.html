gateway-api-migration

Migrate an NGINX Ingress footprint (master/minion or standalone) to Gateway API side-by-side with the original, for per-hostname DNS cutover at the operator's pace. Dual-target: default Traefik (GatewayClass=traefik), opt-in GKE Gateway (--gateway-class gke-l7-*). Every deterministic step is delegated to a bundled script; the master source is never modified.

Pipeline — red borders are halt gates, blue are atomic writers
Step 0 · Gate
Tool check
kustomize · yq · jq · kubectl · python3 required → HALT if missing. kubeconform + ingress2gateway optional (WARN, skip 4b/4c).
Step 0b · Gate
Cluster preflight
check_cluster_preflight.sh — kubectl, GatewayClass, CRDs, namespaces. halts[] → stop; warnings[] → risk register.
Step 1
Discover
kustomize build each overlay → classify_ingress.py → pair_minions.py. Orphan minion / ambiguous pairing → HALT.
Step 2 · Gate
Analyze + confirm
3-bucket annotation inventory, backend port resolution, overlay variance. Operator must confirm before conversion.
Step 3A
Generate common.gateway/
Gateway + per-host listeners + tls-redirect + target policies (Traefik Middleware vs GCPBackendPolicy). Temp dir → atomic rename.
Step 3B
HTTPRoutes
Per (env, minion) HTTPRoute + idempotent kustomization.yaml edits — full-content backups taken first. Build fails → rollback.
Step 4 · Gate
Validate
4a build both modules · 4b kubeconform · 4c ingress2gateway diff · 4d validate_generated.py (11 semantic checks). 4a/4d fail → HALT.
Steps 5–6
Report + runbook
build_report.py renders report.md from state.yaml (verdict PASS / MANUAL REVIEW / FAIL); MIGRATION.md cutover runbook emitted.
Step 7
Pre-commit hints
Commit message + git add file list printed. Never auto-commits — the operator drives git.
Usage — dual-target via one argument
*gateway-migrate # interactive discovery mode
*gateway-migrate <module-path> # default --gateway-class traefik
*gateway-migrate <module-path> --gateway-class gke-l7-global-external-managed
*gateway-migrate <module-path> --resume # resume from state.yaml
*gateway-migrate <module-path> --offline # skip Step 0b cluster checks
*gateway-migrate <module-path> --source-class traefik --no-redirect # chained after *nginx-to-traefik
