Migration Journey

ingress-nginx → Traefik → Gateway API. Four cluster states, seven Zeus commands. The journey is gradual and DNS-reversible — each step can be validated before proceeding.

DNS cutover
S3
Only Traefik
All traffic via Traefik. nginx idle. Retire per env (*retire-nginx) or archive repo-wide (*decommission-nginx).

Migration completion checklist

  • Traefik controller installed (S1)
  • Ingress classes swapped (S2)
  • HTTPRoutes Accepted=True
  • nginx decommissioned (S3)
