*decommission-nginx

Archives the common.nginx/ Kustomize module and removes ingress-nginx from the cluster via ArgoCD prune. This is the final step that takes the cluster from S3 (Traefik only, nginx idle) to a fully decommissioned state.

Safety preconditions (enforced before any action)

  • Zero Ingress objects remain with ingressClassName: nginx or the deprecated annotation
  • ingress-nginx pod has received zero requests for at least N minutes (optional: traffic check)
  • Traefik is the only active ingress controller — all Ingresses/HTTPRoutes resolve via Traefik
  • DNS cutover is complete — no CNAME or A record still points at the nginx LB IP
⛔ Never run helm uninstall ingress-nginx directly. Always decommission via ArgoCD prune — this preserves audit history and respects sync waves. Direct helm uninstall bypasses the GitOps flow.

What it does

  • Verifies all preconditions (fails fast with a clear error if any are unmet)
  • Removes common.nginx/ from the ArgoCD Application's source path
  • Moves the module directory to _archived/common.nginx/ (preserves history)
  • ArgoCD prune removes the nginx Deployment, Service, IngressClass, and RBAC from the cluster
  • Updates common.traefik/values.yaml: sets isDefaultClass: true now that nginx is gone

Archive pattern

# Before
common.nginx/
  kustomization.yaml
  values.yaml

# After decommission
_archived/common.nginx/
  kustomization.yaml    # preserved for audit
  values.yaml

# ArgoCD prune removes all nginx resources from cluster
# No helm uninstall — ArgoCD owns the lifecycle

Verification after decommission

kubectl get pods -n ingress-nginx   # namespace empty or deleted
kubectl get ingressclass             # only "traefik" present
kubectl get ingress -A               # zero results (all migrated to HTTPRoute)
kubectl get httproute -A             # all Accepted=True

Migration complete — what's next

  • *health — full cluster health check confirming Traefik-only state
  • *full — runs the full Zeus pipeline on the cleaned-up repo state
  • Consider bumping Traefik chart version via Horus *upgrade — post-migration is a good time
