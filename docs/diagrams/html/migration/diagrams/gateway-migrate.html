*gateway-migrate

Replaces the Ingress API with Gateway API (Gateway + HTTPRoute). The master Ingress becomes a Gateway; each minion Ingress becomes an HTTPRoute that references it. Introduced in v1.7.0 of the skill pack.

What it does

  • Detects master Ingress (no path rules, just TLS) → generates a Gateway resource
  • Detects minion Ingresses (path rules) → generates HTTPRoute resources referencing the Gateway
  • Adds the GatewayClass for Traefik (traefik) if not present
  • Removes the old Ingress objects from the Kustomize base
  • Updates common.traefik/kustomization.yaml to include the Gateway resource

Before — master + minion Ingress

# Master Ingress (no rules — just TLS termination)
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: gateway-master
  annotations:
    nginx.ingress.kubernetes.io/use-regex: "true"
spec:
  ingressClassName: nginx
  tls: [{hosts: ["*.example.com"], secretName: tls-cert}]

After — Gateway + HTTPRoute

# Gateway (replaces master Ingress)
apiVersion: gateway.networking.k8s.io/v1
kind: Gateway
metadata:
  name: traefik-gateway
  namespace: traefik
spec:
  gatewayClassName: traefik
  listeners:
    - name: https
      port: 443
      protocol: HTTPS
      tls:
        certificateRefs: [{name: tls-cert}]
      allowedRoutes: {namespaces: {from: All}}

# HTTPRoute (replaces minion Ingress)
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: my-service
spec:
  parentRefs: [{name: traefik-gateway, namespace: traefik}]
  hostnames: ["my-service.example.com"]
  rules:
    - matches: [{path: {type: PathPrefix, value: /}}]
      backendRefs: [{name: my-service, port: 80}]

Verification

kubectl get gateway -n traefik          # Ready=True
kubectl get httproute -A                 # Accepted=True, ResolvedRefs=True
curl -sk https://my-service.example.com  # HTTP 200
