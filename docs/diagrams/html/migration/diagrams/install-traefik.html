*install-traefik

Scaffolds the common.traefik/ Kustomize module and deploys the Traefik controller alongside ingress-nginx. After this step both controllers run in the cluster simultaneously (S1 — dual-controller state).

What it does

  • Creates common.traefik/kustomization.yaml with helmCharts stanza (Traefik chart)
  • Creates common.traefik/values.yaml with isDefaultClass: false (nginx stays default at S1)
  • Creates an ArgoCD Application for common.traefik/ with enableHelm: true
  • Does NOT touch any service Ingresses — nginx still handles all traffic at S1
  • Validates the Traefik pod is Running before reporting success

Generated common.traefik/kustomization.yaml

apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
helmCharts:
  - name: traefik
    repo: https://helm.traefik.io/traefik
    version: "32.1.0"
    namespace: traefik
    valuesFile: values.yaml
# ArgoCD Application (separate file) must set:
# spec.source.kustomize.enableHelm: true

Safety preconditions

  • Cluster must be reachable and authenticated
  • common.traefik/ must not already exist (idempotent check)
  • Traefik namespace created; GatewayClass CRDs installed if --enable-gateway

Verification after apply

# Both controllers should be healthy:
kubectl get pods -n traefik        # Traefik Running
kubectl get pods -n ingress-nginx  # nginx still Running
kubectl get ingressclass           # both traefik + nginx present
# No service Ingresses changed yet — all traffic still via nginx
