Overview / common.service

common.service — Data Plane

The per-service Kustomize module that manages Deployments, Services, and Ingress/HTTPRoute objects. This is the data plane — it consumes the controller (common.traefik) but updates independently. Each service team owns a subdirectory under common.service/.

Purpose

  • One Kustomize base per service + three env overlays (dev, stg, prd)
  • Ingress objects point at ingressClassName: traefik (post S1) or nginx (S0)
  • Post-migration: Ingress replaced by HTTPRoute pointing at the Traefik GatewayClass
  • Independent ArgoCD Application — controller upgrades don't trigger service re-deploys

Key config — Ingress (during S1/S2)

# common.service/base/ingress.yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: my-service
  annotations:
    kubernetes.io/ingress.class: ""  # patched per env
spec:
  ingressClassName: traefik       # after *nginx-to-traefik
  rules:
    - host: my-service.example.com
      http:
        paths:
          - path: /
            pathType: Prefix
            backend:
              service:
                name: my-service
                port: { number: 80 }

Key config — HTTPRoute (post-migration S3)

# common.service/base/httproute.yaml
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: my-service
spec:
  parentRefs:
    - name: traefik-gateway
      namespace: traefik
  hostnames: ["my-service.example.com"]
  rules:
    - matches: [{ path: { type: PathPrefix, value: / } }]
      backendRefs: [{ name: my-service, port: 80 }]

Dependencies

common.traefik (controller) ArgoCD Application GatewayClass (post S2)

Zeus pipeline touchpoints

  • *scaffold — generates a new service directory under common.service/ with base + overlays
  • *nginx-to-traefik — swaps ingressClassName from nginx → traefik in all service bases
  • *nginx-to-gateway — replaces Ingress objects with HTTPRoute in the full chain
  • *ingress-to-gateway — auto-detects source class and migrates individual modules
  • *full — validates all service Kustomize builds + ingress/HTTPRoute health
