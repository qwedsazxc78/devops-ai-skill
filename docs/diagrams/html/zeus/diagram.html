Zeus — GitOps Architecture

Kustomize renders per-environment manifests; ArgoCD continuously syncs them to GKE. The ingress layer splits into a controller plane (common.traefik/) and a data plane (common.service/).

Deployment health checklist

  • kustomize build green (no errors)
  • ArgoCD Application synced
  • Traefik controller healthy
  • HTTPRoutes Accepted=True
