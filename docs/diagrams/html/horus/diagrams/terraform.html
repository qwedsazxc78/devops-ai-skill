Overview / Terraform

Terraform — Infrastructure Modules

HCL modules provision GKE clusters, node pools, VPCs, IAM bindings, and supporting cloud resources. Horus gates every apply with *validate (syntax + semantics) and *security (tfsec/checkov) before any infra changes land.

Purpose

  • GKE cluster + node pools (standard + spot) provisioned declaratively
  • VPC, subnets, firewall rules, Cloud NAT managed in code
  • IAM service accounts + Workload Identity bindings per workload
  • Outputs feed into Helm values.yaml (e.g. cluster endpoint, project ID)

Key config — GKE module block

# modules/gke/main.tf
module "gke" {
  source  = "terraform-google-modules/kubernetes-engine/google"
  version = "~> 31.0"

  project_id         = var.project_id
  name               = var.cluster_name
  region             = var.region
  network            = module.vpc.network_name
  subnetwork         = module.vpc.subnets_names[0]
  kubernetes_version = "1.31"
}

Dependencies

Terraform ≥ 1.6 Google provider ≥ 5.0 tfsec / checkov (CI) tflint (linting)

Horus pipeline touchpoints

  • *validate — runs terraform fmt -check + terraform validate
  • *security — runs tfsec + checkov; blocks on HIGH/CRITICAL findings
  • *full — runs validate + security + tflint in sequence, produces report
  • *cicd — suggests pipeline improvements for Terraform apply workflows
