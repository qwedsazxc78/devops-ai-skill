ArtifactHub — Version Discovery

ArtifactHub is the upstream Helm chart registry. Horus's *upgrade pipeline queries it for the latest chart version, compares it against the pinned version in the repo, and proposes an atomic 3-file version bump for review.

Purpose

  • Single authoritative source for latest Helm chart versions
  • *upgrade queries the ArtifactHub API: GET /api/v1/packages/helm/{repo}/{chart}
  • Produces a diff showing pinned → latest, per chart
  • Never auto-applies — outputs a human-reviewable version bump proposal

Atomic 3-file bump example

# *upgrade proposes changes to all 3 files atomically:
#   helm/traefik/Chart.yaml       → dependency version
#   helm/traefik/values.yaml      → image tag
#   helm/traefik/Chart.lock       → checksum

# Chart.yaml diff
- version: "30.1.0"
+ version: "32.1.0"

# values.yaml diff
- tag: "v3.1.0"
+ tag: "v3.3.4"

Dependencies

ArtifactHub API (public, no auth) Outbound HTTPS from CI

Horus pipeline touchpoints

  • *upgrade — full version discovery + diff + atomic bump proposal per chart
  • *full — includes a version-freshness summary table in the report
