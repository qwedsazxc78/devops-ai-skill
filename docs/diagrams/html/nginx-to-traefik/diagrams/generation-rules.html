Traefik Ingress generation rules

The eye-of-horus-gitops conventions are baked into the generator and the kustomization editor: new Traefik Ingresses are first-class resources: entries, and names that Kustomize must not rewrite are written verbatim.

Step 3 · One generated file per service

generate_traefik_ingress.py \
  --input  <service>-nginx-ingress.yaml \
  --output <service>-traefik-ingress.yaml
# stderr WARN lines  → state.yaml.warnings[]
# SHA256 of output   → state.yaml.outputs.traefikIngresses[].sha256
# exit code != 0     → HALT

Annotation mapping follows references/annotation-translation.md (read at Step 3). Each output is recorded in the hand-off contract:

outputs:
  traefikIngresses:
    - { file: argocd-traefik-ingress.yaml, host: argocd.dev.example.com,
        namespace: argocd, backend: argocd-server, port: 80, sha256: <hex> }

When chained under *nginx-to-gateway, this list is exactly what gateway-api-migration consumes via --source-class traefik --source-state <statePath>.

Step 5 · Kustomization edit — resources, not patches

update_kustomization.py --overlay-dir <overlay> \
  --replace <service>-nginx-ingress.yaml=<service>-traefik-ingress.yaml \
  --drop-patch <service>-nginx-ingress.yaml
# idempotent: re-running on a complete state is a no-op
# kustomization.yaml schema mismatch → HALT
  • The Traefik file is added to resources: — Traefik Ingresses never live in patches:.
  • The nginx entry is dropped from patches: in the same edit.

Verbatim names — namePrefix does not touch them

Backend Service names and TLS secretName are written verbatim into the generated Ingress: Kustomize namePrefix does not rewrite them, so copying a prefixed or guessed name would break routing or TLS after build.

FieldRule
spec.rules[].backend.service.nameVerbatim from the nginx source — never prefixed
spec.tls[].secretNameVerbatim from the nginx source — never prefixed
ingressClassNameAlways traefik
⚠ This is the core class-swap invariant: only the Ingress class and file placement change — the backends and certificates the service already uses stay byte-identical.

Step 6 · Managed-cert host list

Every new Traefik Ingress's primary host must be present in common.traefik/overlays/<env>/app.ingress.yaml under both spec.tls[].hosts and spec.rules[].host:

update_kustomization.py --app-ingress <path> --add-host <host>
